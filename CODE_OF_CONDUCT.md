# Code of conduct

We want aispace to be a useful and welcoming project for people with different backgrounds and
levels of experience.

Be respectful, specific, and constructive. Critique ideas and code rather than people. Do not use
harassment, threats, discriminatory language, unwanted sexual attention, deliberate intimidation,
or sustained disruption. Protect other people's private information, including credentials and
private file links.

Maintainers may edit or remove contributions that violate these expectations and may temporarily
or permanently restrict participation when necessary. Report conduct concerns privately to
contacts@aispace.sh. Reports will be reviewed in confidence and handled as promptly as practical.

This code applies in repository spaces and in public spaces where someone is representing the
project.
